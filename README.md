A standalone, GitHub-compatible git forge in one Node 22 process: git smart HTTP (upload-pack v2, receive-pack v0), REST v3, GraphQL and MCP, served from its own in-memory store — no git binary, no database, no outside service.

## Run it

```sh
node --experimental-strip-types main.ts
```
